# MyBibleWalk_DB

MyBibleWalk 앱이 내려받아 읽기 전용으로 보여 주는 **검증본 권 개관** 자료 저장소입니다.
(앱 소스는 이 저장소에 없습니다.)

## 이 저장소에 있는 것
- `books/` — 권별 개관 파일(`01_창세기.json` … 66권). 문장마다 근거 번호가 붙어 있습니다.
- `index.json` — 파일 목록과 갱신 날짜. 앱이 가장 먼저 읽습니다.
- `docs/SCHEMA.md` — 파일 형식과 근거 표기 규칙.

## 근거 표기 원칙
1. 근거가 있는 문장 끝에 번호(예: `[3]`)를 달고, 같은 파일 맨 아래 `refs`에 그 번호의 출처를 적습니다.
2. 출처에는 저자·제목·출판 정보, **정확한 위치**(쪽, 장·절, 글 안의 소제목), 주소(URL), 열람일을 적습니다.
3. 각 출처에는 **확인 수준**을 표시합니다.
   - `full` — 해당 본문을 직접 열어 읽고 확인함
   - `abstract` — 초록·발췌까지만 확인함(전문은 못 봄)
   - `secondary` — 다른 글이 인용한 것을 통해 확인함(원문 직접 확인 못함)
4. 근거 번호가 없는 문장은 근거 없는 정리 문장으로 따로 표시합니다.
5. 출처가 단정하지 않는 내용은 단정하지 않습니다(조사·어미 포함). 학계 견해가 갈리면 갈린다고 적습니다.
6. 저작권이 있는 글은 옮기지 않고 요약·재서술하며, 원문 발췌는 저장소에 싣지 않습니다. 출처·위치·공식 링크만 적고, 공식 사이트가 없으면 성경 역본·권·장·절만 적습니다(`tools/check_no_excerpts.py`가 검사).

## 주의
- AI와 사람이 함께 작업한 참고 자료이며 오류가 있을 수 있습니다. 중요한 내용은 근거로 적힌 원자료를 확인하세요.
- 이 저장소의 글은 성경 본문이 아닙니다. 성경 역본의 저작권은 각 권리자에게 있습니다.
- 이용 조건(라이선스)은 저장소 소유자가 정해서 이 문서에 따로 적을 예정입니다. 정해지기 전에는 저장소 소유자의 허락 없이 재배포하지 마세요.

## 앱이 읽는 주소
공개 저장소의 파일은 GitHub가 자동으로 제공하는 주소로 읽을 수 있습니다.
`https://raw.githubusercontent.com/leedabid/MyBibleWalk_DB/main/index.json`

## 업데이트 알림용 지문 (rev)
DB 파일을 고친 뒤 커밋 전에 `python3 tools/make_index.py`를 실행하면 index.json의 rev가 갱신되고, 앱이 "업데이트 있음"을 알립니다. 앱 새 버전을 알리려면 app.json의 versionCode/versionName을 올립니다.
