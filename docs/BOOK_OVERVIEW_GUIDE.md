# 권 개관 작성 지침 (66권 공통)

출애굽기는 "한 권을 잘 만드는 법"이 아니라 **모든 권에 같은 방법을 쓰기 위한 시험대**입니다. 아래 규칙은 출애굽기에서 겪은 문제(지리가 권 하나로 끝나지 않음, 문장마다 근거가 필요함, 다른 권과의 연결을 어떻게 말할 것인가)에서 나왔습니다.

## 1. 권 개관이 답해야 할 질문

> 이 권은 무엇이며, 성경 전체 안에서 어디에 서 있고, 앞뒤 다른 권과 어떻게 이어지는가?

그래서 한 권의 개관은 아래 여섯 덩어리를 가집니다. (구절 해석은 '본문 주해'가 따로 맡습니다.)

| 덩어리 | 내용 | 분과(보스 4분과 기준) | 근거 방식 |
|---|---|---|---|
| A. 기본 | 이름, 저자·연대에 대한 전승과 학계 입장, 장르, 한눈에 보기 | 성경개론 | 해석 자료(각주) |
| B. 구조·흐름 | 장 단위 개요, 큰 단락의 전개 | 성경개론 | 해석 자료(각주) |
| C. 배경 | 역사·연대, **지리**, 문화, 언어 | 성경개론(배경) | 지리는 자료 기반, 나머지는 해석 자료 |
| D. 정경 안의 위치 | ① 앞 권에서 받은 것 ② 이 권이 뒤로 준 것(구약 안, 신약의 인용·암시) ③ 이어지는 주제(언약·성막·유월절 등) | 성경신학 | **연결 수치는 자료 기반, 설명은 해석 자료** |
| E. 해석 쟁점 | 저작·연대·방법에 대한 논쟁. 입장별로 나란히 | 성경개론/조직신학 접점 | 입장마다 이름 있는 자료 |
| F. 읽기 도움 | 핵심 구절, 어려운 대목 | 본문 주해로 연결 | 해석 자료 |

## 2. 근거는 두 종류이고 섞지 않는다

1. **자료 기반** (스크립트가 공개 데이터에서 계산 → 누가 다시 해도 같은 결과)
   - 지리: OpenBible.info Bible Geocoding Data (CC BY 4.0)
   - 다른 권과의 연결 수치: OpenBible.info Cross-references (CC BY). 득표는 "함께 읽을 연결"을 지지한 정도이지 **인용이나 영향의 크기가 아닙니다.** 문장에도 그렇게 적습니다.
   - 스크립트: `tools/crossref_links.py <권 번호> <cross_references.txt>` (66권 공통)
2. **해석 기반** (사람이 쓴 문장) — 이름 있는 자료(성경 사전·주석·스터디 바이블·논문)의 해당 위치를 각주로 달고, 자료가 말하는 정도 이상으로 단정하지 않습니다. 자료마다 입장이 다르면 다르다고 적습니다.

"이 권이 다른 권에 영향을 주었다"는 문장은 **해석 기반**입니다. 상호참조 수치만으로는 쓰지 않습니다.

## 3. 여러 권에 걸치는 자료는 한 곳에 둔다 (`shared/`)

- 출애굽→가나안 여정은 출애굽기·민수기·신명기·여호수아에 걸쳐 있습니다. 권마다 복사하면 서로 어긋납니다.
- 그래서 `shared/geo.json`에 지명과 여정을 한 번만 두고, 각 권은 `geo: { shared, journeys[], focus }`로 **가리키기만** 합니다. 앱은 권을 받을 때 공용 파일도 함께 받습니다.
- 같은 원칙으로 나중에 `shared/timeline.json`(연대), `shared/themes.json`(주제 추적: 언약·성막·유월절·새 출애굽 등)을 둡니다. 권마다 "이 권이 이 주제의 어느 대목을 맡는지"만 적습니다.

## 4. 장르별 무게 (같은 틀, 다른 강조)

| 장르 | 특히 힘줄 곳 |
|---|---|
| 율법·모세오경 | 언약 구조, 법전 비교, 절기, 다음 권(신명기)에서의 재진술 |
| 역사서 | 연대·지리 여정, 앞 권 약속의 성취, 열왕기·역대기 같은 병행 본문 비교 |
| 시가서 | 시 유형·표제, 구속사 회상 시편(예: 출애굽 회상), 신약 인용 |
| 예언서 | 역사적 배경, 이전 사건의 재현(새 출애굽 등), 신약에서의 성취 방식 |
| 복음서 | 구약 인용·암시, 공관복음 병행, 지리 동선 |
| 서신 | 수신자·상황, 구약 사용 방식, 핵심 교리 단락 |
| 묵시 | 구약 이미지의 재사용, 해석 전통 구분 |

## 5. 한 권을 만드는 순서

1. 공용 자료 갱신 확인(지리·연대·주제)과 이 권이 가리킬 항목 정하기.
2. `crossref_links.py`로 연결 수치 생성 → 섹션 "다른 권과의 연결(상호참조 그물)"에 그대로 넣기.
3. 해석 기반 섹션 작성: 문장마다 각주. 자료를 **직접 열어** 확인하고 수준을 기록(`full` 원문 확인 / `abstract` 요약·검색 결과만 / `secondary` 2차 자료 / `reference` 구절 위치만 제시, 본문 미확인).
4. `reference` 수준 문장은 **`verified`로 올리기 전에 반드시 본문과 대조**. 대조하기 전에는 상태를 `draft`로 둔다.
5. 사건·날짜 표기는 구절을 함께 적는다(예: 1월 15일, 민 33:3).
6. 자료가 약한 곳은 비워 두고 `notes`에 "미작성"을 밝힌다. 추측으로 채우지 않는다.
7. 미리보기(md)를 만들고 사용자가 읽어 확인.

## 6. "이 권이 다른 권에 준 영향"을 어떻게 다룰까 — 조사 질문 틀

각 권마다 아래 질문에 **이름 있는 자료를 찾아** 답합니다. (질문 자체는 근거가 아닙니다.)

- 구약 안: 이 권의 사건·법·표현이 후대 권에서 회상·재진술·재해석되는 곳은 어디인가? (예: 출애굽기 → 신명기의 재진술, 시편의 구속사 회상, 예언서의 '새 출애굽')
- 신약: 인용(명시), 암시, 모형(유형론) 중 어떻게 쓰였는가? 인용 목록은 어느 자료가 기준인가?
- 반대 방향: 이 권을 이해하려면 앞 권의 무엇이 필요한가?
- 상호참조 수치가 몰린 장(예: 출애굽기 20·15·23·32·12장)은 왜 몰렸는가?

## 7. 시범 세 권을 고른 이유

출애굽기(율법+서사), 로마서(서신·교리, 구약을 많이 쓰는 글), 마가복음(복음서, 구약 인용·병행). 장르가 달라 이 틀이 모든 권에 통하는지 가장 빨리 시험할 수 있습니다. 세 권을 끝낸 뒤 틀을 고치고, 그 뒤에 나머지 63권으로 넓힙니다.
