# MyBibleWalk 처음 설치 안내

처음 쓰시는 분을 위한 안내입니다. 순서대로 따라 하시면 됩니다. 시간은 5분쯤 걸립니다.

## 1. 설치 파일 받기

1. 폰의 인터넷(크롬, 삼성 인터넷 등)으로 아래 주소를 엽니다.
   **https://github.com/leedabid/MyBibleWalk_DB/releases/latest**
2. 화면 아래쪽 **Assets** 아래의 **`MyBibleWalk_숫자.apk`** 를 누릅니다. (예: `MyBibleWalk_1.14.5.apk`)
3. "이 파일은 기기를 손상시킬 수 있습니다" 같은 안내가 뜨면 **확인** 또는 **다운로드**를 누릅니다. 설치 파일은 3MB 정도입니다.

## 2. 설치하기

1. 다운로드가 끝나면 **열기**를 누르거나, 폰의 **내 파일 > 다운로드**에서 받은 파일을 누릅니다.
2. 처음 한 번은 **"이 출처의 앱 설치 허용"** 스위치를 켜라고 나옵니다. 켠 뒤 **뒤로가기**를 누르고, 설치 화면에서 **설치**를 누릅니다.
3. "Google Play 프로텍트가 앱을 확인하지 못했습니다" 같은 경고가 뜰 수 있습니다. 개인이 직접 올린 앱이라서 나오는 안내입니다. **더보기 > 무시하고 설치** (또는 **그래도 설치**)를 누릅니다.
4. 삼성 갤럭시에서 설치가 계속 막히면 **설정 > 보안 및 개인정보 보호 > 자동 차단**이 켜져 있는지 보세요. 켜져 있으면 설치하는 동안만 끄셔도 됩니다.

설치가 끝나면 **열기**를 눌러 앱을 시작합니다.

## 3. 처음 열었을 때

- **성경 파일이 없어도 바로 읽을 수 있습니다.** 앱 안에 **한국어 성경 1910**과 영어 **BSB** 전체 본문이 들어 있습니다(둘 다 누구나 자유롭게 쓸 수 있는 번역입니다).
- 아래쪽 메뉴: 읽기 · 검색 · 노트 · 창조(연대표) · 읽기표 · AI 질문 · 설정.

## 4. 개관·연대표 자료 받기 (한 번만, 인터넷 필요)

권별 **개관**(지도·여정 포함)과 **연대표** 자료는 설치 파일에 들어 있지 않고 인터넷으로 받습니다.

1. 아래 메뉴 **설정**을 누릅니다.
2. 위쪽 하위 메뉴 줄에서 **업데이트**를 누릅니다.
3. **확인**(업데이트 확인) 후 알림창에서 **자료 받기**를 누릅니다. 66권 개관과 연대표를 한 번에 받습니다.
4. "모두 최신으로 바꿨습니다."가 나오면 끝입니다. 이후에는 인터넷이 없어도 열립니다.

받지 않은 책의 개관도 그 책 개관을 열 때 인터넷이 있으면 자동으로 받아 옵니다.

## 5. 앱 새 버전이 나왔을 때

앱을 켜면 새 버전이 있을 때 알림창이 뜹니다(하루에 두 번까지만 확인합니다). **새 앱 설치하기**를 누르면 앱이 설치 파일을 받아 설치 화면을 띄웁니다. 설치를 누르면 끝이고, **쓰던 기록과 노트, 설정은 그대로 남습니다.** 처음 한 번만 "이 앱의 설치 허용"을 켜 주세요.

## 6. 선택 사항

- **내 성경 파일(.bdf) 쓰기:** 폰의 `bible` 폴더에 가지고 계신 성경 파일이 있으면 설정 > 데이터 소스에서 그 폴더를 고르면 그 역본들이 나옵니다. 그 파일은 앱에 포함되어 있지 않으며, 본인이 사용할 권리가 있는 파일만 쓰세요.
- **AI 질문:** 쓰려면 본인이 만든 Gemini API 키를 설정 > AI 설정에 넣어야 합니다. 키는 앱에 들어 있지 않습니다.
- **노트 백업:** 노트는 선택한 성경 폴더의 `mybiblewalk_notes.json`에 저장됩니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 설치 파일이 열리지 않음 | 내 파일 > 다운로드에서 파일을 직접 누르세요. |
| "앱이 설치되지 않았습니다" | 이미 다른 서명으로 설치된 같은 앱이 있을 수 있습니다. 기존 앱을 지우면 노트가 사라질 수 있으니, 먼저 노트를 백업하세요. |
| 자료 받기가 실패함 | 와이파이를 확인하고 다시 눌러 보세요. 일부만 받아졌다면 한 번 더 누르면 나머지를 받습니다. |
| 개관이 안 열림 | 설정 > 업데이트에서 자료를 받았는지 확인하세요. |

## 알아 두실 점

- 이 앱은 개인이 만든 무료 앱이며, Google Play 스토어에는 올라 있지 않습니다.
- 성경 본문의 출처는 저장소의 `NOTICE_BIBLES.md`(앱 소스 저장소)에 있고, 개관 자료의 이용 조건은 이 저장소 README를 보세요.
- AI와 사람이 함께 만든 참고 자료라 오류가 있을 수 있습니다.
